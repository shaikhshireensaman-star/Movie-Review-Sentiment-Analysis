#### Movie Review Sentiment Analysis (NLP)

#### 📌 Project Overview

An end-to-end Natural Language Processing (NLP) research and machine learning project developed in **Google Colab** to classify 50,000+ movie reviews into positive and negative sentiments. 

#### 🛠️ Tech Stack & Tools

* **Language:** Python
* **Environment:** Google Colab
* **Libraries:** Pandas, NumPy, Scikit-learn, NLTK / SpaCy, Hugging Face Transformers, Matplotlib / Seaborn

#### ⚙️ Key Workflow & Methodology

1. **Data Cleaning & Preprocessing:** Removed HTML tags, punctuation, and stop words; applied tokenization and lemmatization across 50,000+ text reviews.
2. **Feature Engineering:** Extracted numerical text representations using **TF-IDF Vectorization** and pre-trained transformer embeddings.
3. **Model Training & Comparison:** Trained and benchmarked multiple supervised classification models including **Logistic Regression**, **Multinomial Naive Bayes**, and **Hugging Face Transformer** baselines.
4. **Evaluation:** Evaluated model performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix visualizations.

#### 📊 Results

* Achieved **89% classification accuracy** and an **0.88 F1-score** on the test dataset.
